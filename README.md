# Terrain3D macOS compatibility builds

A manual, bounded build of public Terrain3D v1.1.0 source with explicit older macOS deployment targets.
Only the public upstream addon and its pinned godot-cpp dependency are checked out.
No game projects, tracks, artwork, private source, settings or credentials are included.
Standard: universal x86_64/arm64, target13.0. Legacy: x86_64, target10.15.
A native ARM64 Godot4.7.2 class-registration smoke is included; this does not prove a full game or Catalina run.
Upstream sources and license notices remain unchanged. Binaries are temporary artifacts retained for one day.
